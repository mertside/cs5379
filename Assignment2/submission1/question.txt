I dropped "er" in an intended word "sender" in the previous email, here is the updated description of Assignment 2.

The requirement of Assignment 2 is to write
(1) a short description of your technical idea for implementing barrier using MPI_Send()'s and MPI-Recv()'s, and
(2) a MPI C code,  containing a segment of code that
(2.1) implements your technical idea for implementing the functionality of barrier using  MPI_Send()'s and MPI-Recv()'s, and
(2.2) the code has a parallel time complexity of no more than 8 log_2 N steps, where N is the number of processes (for simplicity, you may assume N is a power of 2), and a step refers to time incurred by the sending of a message by a sender and the receiving of the message by the receiver, and if there are multiple pairs of simultaneous send-receive between different non-overlapping pairs of sender-receiver, it is also considered one step (please see discussions in previous 3 classes for the communication steps in implementing broadcast and many2one communications using send()'s and recv()'s ).
